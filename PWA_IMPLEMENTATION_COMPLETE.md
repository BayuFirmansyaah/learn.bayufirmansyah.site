## 🐛 Troubleshooting

### Service Worker not registering?
- Check browser console for errors
- Verify HTTPS (required for SW)
- Clear cache and reload
- Check scope in SW registration

### App not installable?
- Verify manifest.json is accessible
- Check all required fields in manifest
- Ensure HTTPS is enabled
- Check browser compatibility

### Icons not showing?
- Generate proper PNG icons (not SVG)
- Verify icon paths in manifest.json
- Clear cache and reload
- Check icon sizes meet requirements

### Build warnings?
- Large bundle warning is expected (1.6 MB)
- Can be optimized by splitting materi files
- Gzipped size is acceptable (399 KB)
