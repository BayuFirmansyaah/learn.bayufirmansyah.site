## 📱 Application Overview

**Ubay Tech** adalah Progressive Web App (PWA) untuk pembelajaran programming yang mencakup:
- 🎓 6 Teknologi: Laravel, Kotlin, Flutter, JavaScript, Python, NodeJS
- 📖 129 Materi pembelajaran lengkap
- 💼 Jasa pembuatan aplikasi mobile & web
- 🏢 PT Ubay Solusi Teknologi - Software House Surabaya

## 🔗 Quick Links

### Development
```bash
npm run dev          # Development server
npm run build        # Production build
npm run preview      # Preview production build
./start-pwa.sh       # Build and preview PWA
```

### Features
- ✅ Progressive Web App (PWA)
- ✅ Offline capable
- ✅ Installable on mobile & desktop
- ✅ Fast loading with caching
- ✅ Code splitting & lazy loading
- ✅ SEO optimized

### Tech Stack
- ⚛️ React + Svelte
- ⚡ Vite
- 🎨 Custom CSS
- 🔧 Service Worker
- 📱 PWA
